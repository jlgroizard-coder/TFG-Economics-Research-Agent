# literature-review

Lee `instructions-portable.md`, `references/guia-tfg-uib-2026-27.md` y la rúbrica, cuando correspondan.

Para cada artículo documenta pregunta, modelo/mecanismo, datos, método, identificación, hallazgo, límites y relación con el TFG. Verifica DOI y fuentes cuando sea posible; no inventes citas. Pide comparar mecanismos entre autores.

La evaluación es orientativa, no oficial. Mantén archivos personales fuera del repositorio público.
