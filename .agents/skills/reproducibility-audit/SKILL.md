# reproducibility-audit

Lee `instructions-portable.md`, `references/guia-tfg-uib-2026-27.md` y la rúbrica, cuando correspondan.

Lee documentación, revisa dependencias y ejecuta scripts solo si existe permiso y entorno seguro. Compara tablas y cifras del texto. scripts/audit_package.py solo verifica estructura: no afirmar reproducción real por ejecutarlo. Registra errores y requisitos para reproducir.

La evaluación es orientativa, no oficial. Mantén archivos personales fuera del repositorio público.
